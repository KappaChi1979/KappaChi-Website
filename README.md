# Kappa-Chi-Website
# Authors: Deon Summers & Dylan Woods
# Description: Home Page for the Kappa Chi Chapter of Phi Beta Sigma Fraternity Inc.






## Updating Lineage
Must have Node.js installed on machine
1. Upload images to '~kappachi/LineagePhotos/'
2. Edit member lineage text in 'lineage.json' file
3. Nvigate to the directory '~kappachi/'
4. Run lineage script in terminal`node lineagetohtml.js` (this generates lineage page)




## Updating Chapter page 'Meet the Brothers' Section
Must have Node.js installed on machine
1. Upload images to '~kappachi/chapter/ChapterHeadshots/'
2. Edit member lineage text in 'brothers.json' file
3. In terminal navigate to '~kappachi/chapter/'
3. Run chapter script in terminal 'node chapter_script.js' (this generates chapter page)
